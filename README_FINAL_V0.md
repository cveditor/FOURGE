# FOURGE — Final V0 launch candidate

This is the single V0 branch to test from now on.

## Product rules locked in this build

- Landing page: English only.
- Create Crew: creator chooses ENGLISH or ITALIANO.
- From that point on the whole Crew inherits that locale.
- Wild Card branding/content: always English.
- FOURGE UI brand accent: premium purple.
- Wild Card rarity border: rarity-specific, not always purple.
- AI Wild Card generation is automatic after the ending reveal.

## Final Wild Card architecture

### 1. Master Wild Card — 4:5

Generated at `1088 × 1360`.

The AI creates the cinematic scene using:
- the 4 real player reference photos;
- a fifth generated composition-guide image;
- an ending-family visual preset.

FOURGE then adds deterministic typography server-side with Sharp:
- centered FOURGE logo;
- DROP #01 · THE HEIST;
- rarity badge/border;
- ending title;
- one-line/two-line micro outcome;
- tiny FOURGE footer.

The AI never generates the text.

### 2. Story Share — 9:16

Generated at `1152 × 2048`.

It does NOT crop the Wild Card. The complete 4:5 Master Card is centered inside a 9:16 atmospheric background derived from the same image.

`SHARE TO STORIES` shares the 9:16 asset.
`SAVE WILD CARD` saves the 4:5 Master Card.

## Why the fifth reference image exists

The first four inputs are identity references.
The fifth input is generated by FOURGE and contains only a simple four-person composition diagram and shared ground line.

The prompt explicitly tells the image model:
- images 1–4 = identities;
- image 5 = composition only;
- do not copy image 5 visually;
- all four people must occupy one coherent physical scene and ground plane.

This is specifically intended to reduce bad generations such as one person standing on a roof while the others appear suspended in the air.

## Setup

Keep your existing `.env.local`:

```env
SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_SECRET_KEY=sb_secret_...
FOURGE_TOKEN_SECRET=your-long-random-secret
NEXT_PUBLIC_SITE_URL=http://localhost:3000
OPENAI_API_KEY=sk-...
OPENAI_IMAGE_MODEL=gpt-image-2.5-sunburst
```

If your current FOURGE database already has migrations 001–005, **no new SQL migration is required**.

Then:

```bash
npm install
npm run dev
```

## Test flow

1. Open `/` — landing must be fully English.
2. Click Create Crew.
3. Choose ENGLISH or ITALIANO.
4. Complete creator setup.
5. Join 3 more players through the shared link.
6. Complete all four secret choices.
7. Reveal ending.
8. FOURGE automatically generates the Master Wild Card + Story version.
9. Check:
   - 4 players are grounded in one coherent scene;
   - no faces are merged/duplicated;
   - all Master Card copy fits inside the 4:5 card;
   - Share to Stories produces a full uncropped 9:16 image;
   - stats stay below the card and are not part of the shared image.

## Regenerate

`REGENERATE IMAGE` generates a new AI scene for the same ending and overwrites the V0 Master + Story assets.
