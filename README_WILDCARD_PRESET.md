# FOURGE Wild Card — reference-image AI architecture

FOURGE follows one rule:

**AI generates the scene. FOURGE owns the card.**

The AI does not draw the FOURGE logo, typography, rarity, score, route ranking, player names, borders or UI. It receives the four Crew photos as identity references and creates one cinematic ending scene.

The fixed card then overlays:

- FOURGE branding
- ending name and rarity
- FOURGE score
- deterministic 256-route benchmark
- ending rarity
- Crew names and roles
- challenge/share language

This gives each Crew a unique visual result without losing a consistent brand system.
